# Sales Analytics Dashboard using Power BI

## Overview

An interactive Power BI dashboard developed to analyze sales performance,
customer behavior, profitability, and product insights.

## Objectives

- Analyze sales and profit trends
- Identify top-performing products and customers
- Understand salesperson performance
- Track key business KPIs

## Tools Used

- Power BI
- Power Query
- DAX
- Excel

## Data Model

Implemented a star schema:

### Fact Table
- Orders

### Dimension Tables
- Customers
- Products
- Salespersons
- Date

## Dashboard Features

- KPI Cards
- Sales trend analysis
- Category performance
- Customer analysis
- Salesperson drill-through
- Dynamic titles
- Custom tooltips

## Key Metrics

- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Return Rate
- Average Order Value
